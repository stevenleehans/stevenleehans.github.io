# Adaptive Nudge Loop — research walkthrough

[Open the walkthrough](https://stevenleehans.github.io/research/adaptive-nudge-loop/) · [Hans’s portfolio](https://stevenleehans.github.io/#projects)

Adapted from Hans’s supplied `Adaptive Nudge Loop.html`. The animated interface explains a synthetic messaging sequence; it does not contact research services, deliver WhatsApp messages, collect participant input or run the frequency model. JavaScript controls the scenes and an optional locally synthesised sound. Fonts load from Google Fonts, with system fallbacks.

Eight scenes show prescription intake, a gated language-model translation, illustrative delivery, interaction evidence, a model suggestion, separate recommendation/decision records, deterministic rules, and changes to future unsent messages. The research summary distinguishes the model’s predictive performance from policy performance and keeps clinical and live-loop claims bounded.

Publication adjustments add navigation, study context, accessible scene state and reduced-motion behaviour; replace personal-looking example identifiers and service addresses with demo labels; and keep the phone illustration in the delivery scene so it does not cover the later trace. The original file and research checkout are unchanged.

The findings summary was checked against the thesis source on 14 October 2026. Reported evaluation figures are historical thesis results, separate from the illustrative walkthrough counts and scores.
