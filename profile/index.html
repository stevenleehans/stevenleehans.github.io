RECORDED DATABRICKS WORKSPACE
Data engineering & ML POC

Real-time mobile payment fraud detection lakehouse POC

Built a Databricks lakehouse that takes synthetic payment transactions from raw ingestion to curated features, model serving and monitoring dashboards.

Bronze → Silver → GoldDelta tables · Unity Catalog · 14 pre-transaction model features
DatabricksDelta LakePySparkMLflowAWS S3
Architecture & engineering

Bronze preserves raw input with an explicit schema and ingestion audit. Silver applies data-quality rules and keeps rejected records with reasons. Gold defines a feature contract that excludes post-transaction information. The ML workflow uses chronological splits, MLflow tracking and Unity Catalog registration, followed by a scoring endpoint, drift tables and three SQL dashboards for monitoring, simulated financial impact and operational replay.

The POC uses synthetic PaySim data. Ingestion and monitoring are batch-based; “real-time” refers to the scoring interface. Financial outcomes are simulation estimates. The source documents a previous Databricks execution; current live endpoint status was not reverified.

Local source validation: 488 tests passed; three optional MLflow tests skipped.

OPEN MODELS · MRI · INFERENCE
Ongoing Kaggle project

RSNA knee MRI & open-model learning

Learning how to adapt pretrained vision models to knee MRI, and take model weights through preprocessing, validation and reproducible inference.

Hugging Face → Kaggle inferenceHands-on learning with DINOv2, DINOv3 and RAD-DINO
PyTorchHugging Face TransformersDICOMCoAtNet
From pretrained weights to inference
  1. Load pretrained checkpoints with Hugging Face Transformers, matching the model configuration and image normalisation.
  2. Prepare MRI slices with physical-scale cropping, slice ordering and cached inputs.
  3. Fine-tune and compare models using grouped validation, then save checkpoints for inference.
  4. Run batched inference in Kaggle notebooks and explore local Apple MPS execution, combining study-level predictions.

This is ongoing competition experimentation and deployment learning, rather than a clinical service. Latest experiments remain private; my published report-label dataset provides a public contribution.
